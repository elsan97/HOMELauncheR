# HOMELauncheR - Minecraft Piracy Edition

Красивый лаунчер для Minecraft с пиратскими версиями, встроенным браузером модов и поддержкой сервера fpv2.

## Особенности

- **Красивый дизайн**: Современный интерфейс с градиентами и анимациями
- **Выбор версий**: Поддержка версий от 1.13.2 до 1.20.1
- **Встроенный браузер модов**: Прямой доступ к CurseForge для установки модов
- **Скачивание из интернета**: Автоматическая загрузка версий Minecraft
- **Предустановленная версия 1.20.1**: Готовая к использованию версия с модами
- **Папка fpv2**: Специальная папка версии Minecraft для сервера "costs-guide.gl.joinmc.link"
- **EXE файл**: Готовый к запуску исполняемый файл

## Установка
 *ОБЯЗАТЕЛЬНО* уберите скобки и всё что внутри них в папкахя, у которых в названии скобки, и точка после них.
### Требования
- Java 21 или выше
- Windows 7/8/10/11

### Сборка из исходников

1. Клонируйте репозиторий
2. Установите зависимости:
   ```
   gradlew.bat build
   ```
3. Соберите EXE файл:
   ```
   build_exe.bat
   ```

### Готовая сборка

Запустите `HOMELauncheR.exe` из папки `build/exe/`

## Использование

1. **Выбор версии**: Выберите нужную версию Minecraft из выпадающего списка
2. **Загрузка**: Нажмите "Скачать выбранную версию" для загрузки
3. **Моды**: Используйте встроенный браузер для поиска и установки модов
4. **Сервер fpv2**: Автоматическая настройка для сервера "costs-guide.gl.joinmc.link"
5. **Запуск**: Нажмите "ЗАПУСТИТЬ MINECRAFT" для старта игры
